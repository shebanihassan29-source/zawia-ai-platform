# منصة الزاوية الذكية

واجهة عربية (RTL) لأدوات ذكاء اصطناعي تعليمية، بُنيت لجامعة الزاوية — المركز الإلكتروني للتعليم.

## الأدوات المفعّلة

- **المخططات (Visualize):** تحويل وصف نصي إلى مخطط Mermaid أو رسم SVG (تدفق، تسلسلي، حالات، ER، فئات، خريطة ذهنية، Gantt).
- **محلّل اللغة:** كشف اللغة، مرادفات، تحليل صرفي، تشكيل عربي، ترجمة سريعة.
- **المحادثات:** حوار مع Claude بالعربية.
- **كشف الكتابة بالذكاء الاصطناعي:** تقدير احتمالي أسلوبي مع إشارات وتظليل للجمل.

بقية البطاقات تظهر بعلامة «قريباً».

## ملاحظة مهمة حول التشغيل

الصفحة ملف واحد (`index.html`). الأدوات الذكية تستدعي Claude عبر قدرة `sample` الخاصة بصفحات Claude Artifacts، لذلك **تعمل فقط عند فتح الصفحة داخل claude.ai**.
عند استضافتها خارجه (مثل GitHub Pages) ستظهر الواجهة، لكن الأدوات ستكون معطّلة حتى يُربط الكود بواجهة API خاصة (دالة `sample` في الملف هي نقطة الاستبدال).

## الملفات

- `index.html` — الصفحة كاملة (CSS وJS داخلها).
